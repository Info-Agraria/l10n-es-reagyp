# CLAUDE.md

## What this repo is
Odoo 18 modules for the Spanish REAGYP regime (Régimen Especial de la
Agricultura, Ganadería y Pesca): sale compensation taxes, fiscal positions and
a receipts journal. The core module is `l10n_es_reagyp`. The repo is public and
follows the OCA layout; branch `18.0` targets Odoo 18.

## Rules
The shared rules live in `.claude/rules/` and are copied from a shared
template. Do not edit them here. Change them in the template and copy them
again.
