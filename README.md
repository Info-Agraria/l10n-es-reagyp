# REAGYP for Odoo (Spain)

Fiscal layer for the Spanish **REAGYP** regime (*Régimen Especial de la
Agricultura, Ganadería y Pesca*) for **Odoo 19.0**, by
[Info Agraria](https://github.com/Info-Agraria).

This repository hosts the REAGYP modules. The core module is
`l10n_es_reagyp` (seller side); further REAGYP-related modules will be
added here as they are built.

## Available modules

| Module | Version | Summary |
| --- | --- | --- |
| [l10n_es_reagyp](l10n_es_reagyp/) | 19.0.1.0.0 | Seller-side REAGYP fiscal layer: sale compensation taxes, fiscal position, dedicated receipts journal. |
