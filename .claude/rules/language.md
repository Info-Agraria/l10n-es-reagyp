# Language
- Code, comments, commits, issues, PRs and docs: English.
- File and folder names: English.
- Docs already written in Spanish stay in Spanish until the repo's translation
  issue runs. Do not translate them on touch; edits to them stay in Spanish.
- User-facing strings are English in code and translated through `.po` files.
- Conversation with the user may be in Spanish. That changes nothing above.
