# Writing
Write for a reader whose first language is not English.
- Short sentences. One idea per paragraph.
- Common words. Define each acronym the first time it appears.
- Start with the point. No intro, no closing summary.
- Active voice: "the script creates the bucket", not "the bucket is created".
- Do not use: robust, seamless, leverage, comprehensive, powerful, crucial,
  delve, streamline, cutting-edge, game-changer.
- Bold only for a word the reader must not miss. No emoji.
- Tables for comparisons, numbered lists for steps.
- Facts carry a date or a number, never "recently" or "many".

Example. Not: "This robust module seamlessly leverages SIGPAC data."
Yes: "The module reads recintos from SIGPAC once per campaign."
